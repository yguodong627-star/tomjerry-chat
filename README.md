# 猫和老鼠 · 聊天小屋（Tom & Jerry Chat）

一个纯前端的小网页：在 1940 年代风格的客厅里，和 **汤姆（Tom）**、**杰瑞（Jerry）**、**斯派克（Spike）** 用语音或文字聊天。
角色是矢量 SVG，会呼吸、晃动、眨眼，说话时嘴巴会一张一合；回复按句子流式朗读出来。

- 只有 HTML / CSS / JS，无需安装、无需构建
- 每个角色有独立的人设和聊天记录
- 支持任意 OpenAI 兼容接口（默认 aihubmix），可在页面上搜索、切换模型

## 文件

| 文件 | 说明 |
| --- | --- |
| `index.html` | 页面结构 |
| `style.css` | 全部样式与动画 |
| `characters.js` | 三个角色的 SVG（矢量路径 + 眨眼 / 口型动画层） |
| `app.js` | 全部逻辑：对话、流式请求、语音识别、语音朗读、模型选择 |

## 使用方法

**本地打开：** 下载或克隆本仓库后，直接双击 `index.html`，用 **Chrome** 或 **Edge** 打开即可。

**GitHub Pages：** 仓库 → Settings → Pages → Source 选择 `Deploy from a branch`，分支选 `main`、目录选 `/ (root)`，保存后用生成的网址访问。
（通过 https 访问时麦克风权限更稳定。）

### 操作

- **按住说话**：按住黄色按钮（或空格键）说话，松开发送；按住时向上滑动可取消。
- **键盘图标**：切换到文字输入，回车发送；麦克风图标切回语音。
- **切换角色**：在汤姆 / 杰瑞 / 斯派克之间切换，各自的聊天记录互不影响。
- **模型**：点击标题下方的模型标签，可搜索接口返回的模型列表，或直接输入自定义模型 ID。
- **设置**：双击（手机上长按）左上角标题，或点击右上角的小齿轮。

## 设置 API

第一次打开会弹出设置窗口，需要填写：

| 项目 | 说明 |
| --- | --- |
| API Base | 默认 `https://aihubmix.com/v1`（aihubmix） |
| API Key | 你自己的密钥 |
| 模型 | 默认 `gpt-4o-mini` |

**使用 OpenRouter：** API Base 填 `https://openrouter.ai/api/v1`，模型 ID 用 OpenRouter 的写法，例如 `openai/gpt-4o-mini`。
其他兼容 OpenAI `/chat/completions` 流式接口的服务同样可以使用。

> 🔒 本项目 **不包含任何 API Key**。你填写的密钥只保存在当前浏览器的 `localStorage` 中，只会发送给你填写的 API 地址，不会上传到别处。在公共电脑上用完后，可清除该网站的浏览器数据（localStorage）来删除密钥。

## 语音说明

- 语音识别使用浏览器自带的 Web Speech API，推荐 **Chrome / Edge** 桌面版；需要 **联网**，并在首次使用时 **允许麦克风权限**。
- 不支持语音识别的浏览器（如 Firefox）会自动切换为文字输入。
- 朗读使用系统 / 浏览器自带的中文语音，不同电脑的声音会有所不同；三个角色使用不同的音调和语速。
